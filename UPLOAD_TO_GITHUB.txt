To find the PID:
1. Open Windows Task Manager.
2. Open the Details tab.
3. Find the actual EverQuest/Quarm game process.
4. Note the number in the PID column.
5. Enter that PID in EQ Mob Overlay and click Attach to PID.

If Connection says Access denied, run EQMobOverlay.exe as Administrator.
